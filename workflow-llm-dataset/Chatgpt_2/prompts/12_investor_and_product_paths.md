# Investor Path and Product Path

## Investor path

Purpose:

- show the system clearly and safely
- emphasize readiness, role, learning, first-value, supervision
- avoid engineering-heavy detail unless asked

Likely path:

1. boot / readiness
2. role select
3. workflow learning / bounded memory
4. mission-control overview
5. first-value
6. supervised posture

## Product path

Purpose:

- real user operation
- setup and permissioning
- approved folder ingestion
- workflow-tree creation
- local runtime assistance
- supervised desktop control

## Relationship

Investor mode should be a clear, polished slice of the real product path.
It must not drift too far from product truth.

## Principle

Do not build a fake investor shell that is disconnected from the product substrate.
