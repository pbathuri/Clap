# UI/UX and Desktop Operator

## Product UI direction

The UI should feel like a premium operator desktop, not a generic dashboard and not only a chatbot.

## Core surfaces

- boot / readiness
- role selection
- onboarding / workflow learning summary
- mission-control home
- first-value card
- next-action / operator summary
- trust and approval panel
- inbox / interventions
- review surface
- multi-window mode

## User experience principles

- calm
- premium
- high-signal
- role-aware
- workflow-aware
- transparent
- safe
- not cluttered

## Desktop operator principle

The browser shell should reflect the real workflow-tree and runtime substrate.
It should not be detached demo theater.

## macOS-first desktop interaction

The product must be designed to evolve from:

- local app launch
- permission setup
- approved folder ingestion
- role setup
- workflow learning
- supervised local actions

## First-value principle

The product should quickly show:

- what it learned
- what it can help with next
- what remains supervised
- why the recommendation is relevant
