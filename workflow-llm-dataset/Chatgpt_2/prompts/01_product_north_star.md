# Product North Star

## Vision

Build a local-first, portable, personal agent system that learns how a user works and can assist across files, workflows, and desktop tools.

## Near-term form

- Laptop-hosted software first.
- Later portable dedicated device.
- User launches a local application.
- The application guides setup, permissions, role definition, and workflow learning.
- The system learns how the user works through folders, file patterns, workflow structure, tools, and repeated tasks.
- The system becomes a supervised desktop operator, not just a chatbot.

## Long-term goal

Progress toward:

- all folders
- all file types
- all apps
- all tools used by the user
- all major recurring work patterns

## Product character

- Local-first.
- Privacy-first.
- Approval-gated.
- Simulation-first before live execution.
- Cross-domain.
- Role-aware.
- Workflow-aware.
- Device-oriented.
- Enterprise-capable from the architecture layer.

## Priority user domains

- Analytics / spreadsheets / dashboards.
- Design.
- Coding / engineering.

## User experience ambition

The system should feel like a premium operator desktop:

- learns context
- understands workflows
- proposes actions
- performs supervised actions
- explains what it knows, what it will do, and why
- grows in capability over time without becoming uncontrolled
