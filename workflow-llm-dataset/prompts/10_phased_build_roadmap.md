- verify what is real
- verify what is partial
- remove drift and stale abstractions
- unify state and adapter seams

## Phase B — Workflow-Tree Core

- formalize the recursive workflow/task model
- map existing packs, sessions, and flows onto it
- persist and validate tree state

## Phase C — Agent Runtime Abstraction

- orchestrator runtime
- specialist roles
- execution modes
- resume / replay / audit
- provider abstraction

## Phase D — Environment Interaction

- file system adapter
- desktop tool adapters
- approved folder model
- app control model
- supervised execution model

## Phase E — Product Surface Unification

- browser desktop shell
- onboarding
- mission-control
- first-value
- trust/review/inbox
- live/cached/fallback coherence

## Phase F — Domain Acceleration

- analytics / spreadsheet workflows
- coding workflows
- design substrate workflows

## Phase G — Packaging and Device Path

- laptop-hosted product quality
- install / reset / preflight
- later portable-device transition

## Phase H — Reliability and Evaluation

- latency hardening
- safety validation
- regression gates
- investor/demo readiness
- product mode readiness
