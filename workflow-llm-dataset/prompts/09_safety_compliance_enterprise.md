# Safety, Compliance, and Enterprise Controls

## Posture

Support both personal use and enterprise-grade controls from day 1.

## Safety model

- local-first
- privacy-first
- approval-gated
- simulation-first before live execution
- explicit provenance
- reversible where possible
- policy-enforced tool boundaries

## Enterprise-grade requirements

- auditability
- policy control
- approval trails
- role-aware permissions
- scope-limited execution
- bounded file access
- session trust visibility
- explicit logs of external retrieval

## Sensitive action handling

Always require strong policy + approval for:

- destructive file operations
- data export
- credential-related flows
- actions outside approved folders/apps
- broad web-driven execution
- opaque script execution

## Desktop control principle

Real desktop control is allowed only within:

- explicit permissions
- approved session scope
- visible trust state
- reviewable logs
