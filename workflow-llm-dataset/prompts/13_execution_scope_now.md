# Execution Scope Now

## Long-term direction

The long-term direction is broad:

- all folders
- all file types
- all apps
- all tools the user uses often

## What should be built now

Do not try to solve universal desktop mastery in one pass.

Build now:

- the generalized workflow-tree substrate
- the agent runtime abstraction
- the macOS-first permission and desktop control model
- approved-folder ingestion
- role-aware workflow learning
- the unified browser desktop shell tied to real product state
- supervised execution primitives
- first-class support for analytics / spreadsheets / dashboards, design substrate, and coding workflows

## What should not be pretended complete now

- every app in existence
- unsupervised universal desktop control
- full automatic learning of every workflow without policy or review
- broad enterprise deployment without the proper hardening

## Success now

Success means:

- the architecture is real
- the runtime is real
- the product shell is tied to reality
- supervised local operator behavior is more real
- the next implementation pass becomes much narrower and clearer
